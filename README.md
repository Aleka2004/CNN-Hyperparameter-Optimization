# №2 СӨЖ — Терең оқыту алгоритмдерінде гиперпараметрлерді оңтайландыру

Бұл репозиторийде **Kaggle авторы Muhammet Zahit Aydın** әзірлеген [CNN Hyperparameter Tuning](https://www.kaggle.com/code/muhammetzahitaydn/cnn-hyperparameter-tuning/notebook) жұмысының қазақша түсіндірілген нұсқасы берілген. **Бастапқы жоба бұл репозиторий авторына тиесілі емес.**

## Мақсаты
Digit Recognizer деректеріндегі 28×28 цифр суреттерін танитын CNN моделінің сапасына гиперпараметрлердің әсерін анықтау.

## Әдістер
- CNN-нің үш архитектурасын салыстыру;
- Деректерді қалыптандыру және аугментация;
- Batch size пен SGD, RMSprop, Adam оңтайландырғыштарын зерттеу;
- **Қосылған бөлім:** оқыту жылдамдығы, convolutional блоктар саны және толық байланысқан қабаттағы нейрондар саны бойынша Grid Search және Random Search.

## Бастапқы ноутбукте сақталған нәтижелер
| Тәжірибе | Ең жақсы параметрлер | Accuracy |
|---|---|---:|
| Batch size | 128 | 98.4643% |
| SGD | lr=0.001, momentum=0.99, Nesterov=True | 98.6190% |
| RMSprop | lr=0.001, momentum=0.8 | 98.8095% |
| Adam | lr=0.001, beta1=0.9, beta2=0.99 | 98.8929% |

Бұл сандар **жүктелген Kaggle ноутбугіне бұрыннан сақталған нәтижелер**; жаңа есептеу орындалды дегенді білдірмейді. Финалдық салыстыру ұяшығы Adam үшін 98.8690% көрсетті.

**Grid Search пен Random Search салыстыруының нәтижелері әзірге жоқ**: жаңа соңғы ұяшықты орындағанда `grid_random_comparison.csv` жасалады.

## Google Colab-та ашу
1. `cnn_hyperparameter_tuning_kz.ipynb` файлын Colab-қа жүктеңіз.
2. [Kaggle Digit Recognizer](https://www.kaggle.com/competitions/digit-recognizer/data) бетінен `train.csv`, `test.csv` жүктеп алыңыз.
3. Бірінші код ұяшығындағы файл таңдау терезесінде екі CSV файлын белгілеңіз.
4. Ұяшықтарды кезегімен орындаңыз. Оңтайландырғыштарды толық іздеу ұзақ уақыт алуы мүмкін.
5. Қосымша Grid/Random тәжірибесін орындағаннан кейін нәтижелерді салыстырыңыз.

## Файлдар
- `cnn_hyperparameter_tuning_kz.ipynb` — қазақша мәтін және қосымша Grid/Random тәжірибесі;
- `saved_results.csv` — алынған нәтижелер.
